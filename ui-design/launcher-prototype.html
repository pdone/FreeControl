设备

统一管理所有设备：为每台设备设置别名并映射到连接标识（serial 或 IP:端口），查看实时状态，批量或单独连接 / 断开。点选某台设备查看其拼装命令；展开「参数」可针对该设备覆盖默认参数。

显示源

镜像主屏、虚拟显示器、Flex Display 或摄像头画面。以下为默认参数，可在「设备」页中按设备覆盖。

视频源

--video-source --video-source镜像手机屏幕，或改为采集设备摄像头的画面。摄像头镜像需要 Android 12 及以上；摄像头源下画面不来自设备屏幕，--display-id、--new-display 与 --turn-screen-off 等参数不参与拼装。
显示模式 显示模式主屏镜像设备当前的显示；虚拟显示器在设备上新开一块独立显示；Flex Display 让虚拟屏随窗口连续缩放。Flex Display 下 --crop、--window-width、--window-height 与 --no-control 不参与拼装（scrcpy 判定它们与 --flex-display 不兼容）。
两档虚拟屏的分辨率都在下方指定
显示 id（--display-id） 显示 id（--display-id）镜像指定 id 的设备显示。可用 scrcpy --list-displays 列出可用 id。非 0 值与 --new-display 互斥（scrcpy 拒绝两者同时指定）；摄像头源下该参数不可用。
0 / 留空 = 主屏；虚拟显示器与摄像头源下不生效

虚拟显示器

分辨率（--new-display） 分辨率（--new-display）虚拟显示器的分辨率，格式为「宽x高」。它与下方的密度一起拼成 --new-display=宽x高/密度：只填密度时分辨率沿用主屏尺寸。
留空由 scrcpy 决定：非 Flex 用主屏尺寸与密度，Flex 用 1280x960/160
密度 DPI 密度 DPI虚拟显示器的像素密度，与分辨率一起决定新屏上界面元素的大小。同一分辨率下密度越大，界面元素越大、可容纳的内容越少。
留空用上面的默认密度
关闭时保留内容（--no-vd-destroy-content） 关闭时保留内容（--no-vd-destroy-content）关闭虚拟显示器时，把其中运行的应用移到主屏，而不是随虚拟屏一起销毁。只在虚拟显示器与 Flex Display 下有意义。
移到主屏而非销毁

摄像头

摄像头朝向（--camera-facing） 摄像头朝向（--camera-facing）按朝向选择设备摄像头：front 前置、back 后置、external 外接。不选则由 scrcpy 使用检测到的第一个摄像头。
尺寸（--camera-size） 尺寸（--camera-size）摄像头的采集分辨率，格式为「宽x高」；可选档位由摄像头自身决定，可用 scrcpy --list-camera-sizes 列出。摄像头镜像需要 Android 12 及以上。
留空由 scrcpy 自动选择尺寸
帧率（--camera-fps） 帧率（--camera-fps）摄像头的采集帧率，可选档位同样取决于摄像头。摄像头镜像需要 Android 12 及以上。
留空用 Android 默认的 30 fps
初始缩放（--camera-zoom） 初始缩放（--camera-zoom）摄像头的初始缩放倍数，1 表示不缩放。可调范围由摄像头自身决定，填超出范围的倍数会由 scrcpy 报错。
开启闪光灯（--camera-torch） 开启闪光灯（--camera-torch）启动时点亮摄像头的闪光灯（手电筒）。只在摄像头源下有效。
启动时点亮

视频

编码、分辨率、码率、帧率与画面适配。默认参数。

编码与画质

视频编码（--video-codec） 视频编码（--video-codec）选择视频编码格式。h264 是 scrcpy 的默认值，延迟最低；h265 画质更好但延迟更高；av1 在现有 Android 设备上的编码器还很罕见。选「自动」时按 scrcpy 自身的默认决定。
长边分辨率（--max-size） 长边分辨率（--max-size）限制画面宽与高的最大值，另一边按设备比例推算（Flex Display 除外）。摄像头源下它不裁剪画面，而是用于从摄像头支持的尺寸里挑接近的一档。
自动
视频码率（--video-bit-rate） 视频码率（--video-bit-rate）视频编码的比特率，scrcpy 默认 8 Mbps。越高画面越清晰，占用的带宽与解码资源也越多。
自动
最大帧率（--max-fps） 最大帧率（--max-fps）限制采集帧率，Android 10 起获得官方支持。实际帧率随画面变化：静止画面不会跑满上限。
不限制
视频编码器（--video-encoder） 视频编码器（--video-encoder）指定 MediaCodec 视频编码器（可用的编码器名随 --video-codec 的编码格式而定）。可用 scrcpy --list-encoders 列出设备上可用的编码器。
留空由 scrcpy 自动选择
硬件解码（--hwdec） 硬件解码（--hwdec）「自动」= 不传该 flag：scrcpy 使用第一个可用的硬件解码器，无法解码时回退软件解码。disabled 强制纯软件解码；vaapi 仅 Linux（需系统安装 VA-API 驱动，X11 上还要求 EGL 渲染器）；d3d11va 仅 Windows。显式指定后若硬件解码不可用，scrcpy 直接报错退出。与「后台录制」（--no-window）互斥：该模式隐含 --no-video-playback，而硬件解码要求 video playback；disabled 不受此限。需要 scrcpy 5.0 及以上。
「后台录制」开启时不生效

画面与适配

裁剪（--crop W:H:X:Y） 裁剪（--crop W:H:X:Y）在设备端裁剪画面，四个分量的顺序是「宽:高:x:y」，其中 x、y 是裁剪区域左上角的坐标。坐标以设备自然方向为基准（手机竖放、平板横放）。Flex Display 下不生效。
旋转角度（--angle） 旋转角度（--angle）按给定角度顺时针旋转画面内容，可填任意角度，界面给出 0 / 90 / 180 / 270 四档。只改变画面呈现，不影响录制文件的方向（录制方向由 --record-orientation 单独决定）。
渲染适配（--render-fit） 渲染适配（--render-fit）控制画面在窗口里的适配方式。letterbox 保持宽高比，多出的区域留边；stretched 拉满窗口、不保持宽高比；unscaled 按像素一比一显示，窗口小于画面时只能看到一部分。
视频缓冲（--video-buffer） 视频缓冲（--video-buffer）在显示前增加一段缓冲，用来吸收网络抖动。它以减少卡顿为代价换来画面延迟增加；局域网直连通常不需要。
单位：毫秒

音频

Android 11+ 可转发设备音频，支持多种音源与编码。默认参数。

音频转发

禁用音频转发（--no-audio 开启） 禁用音频转发（--no-audio 开启）开关打开时不转发设备音频：画面照常镜像，声音仍从手机发出。关掉开关才启用音频转发；音频转发需要 Android 11 及以上。
禁用音频转发
音频源（--audio-source） 音频源（--audio-source）选择音频采集来源，只在音频转发开启时才有意义。output 转发整机音频输出并让设备端静音；playback 只采集应用的播放声音（应用可主动退出采集）；mic 系列采集麦克风 —— mic-unprocessed 取原始信号、mic-camcorder 按录像场景调优、mic-voice-communication 启用回声消除与自动增益；voice-call 与 voice-performance 分别对应通话与演出场景。设备实际支持的来源随厂商实现而异。
音频编码（--audio-codec） 音频编码（--audio-codec）选择音频编码格式：opus 为 scrcpy 默认，aac 兼容性好，flac 无损但体积大，raw 不压缩、体积最大。
复制音频（--audio-dup，设备同时播放） 复制音频（--audio-dup，设备同时播放）转发音频的同时让设备继续外放，而不是转发后设备静音。只在音频源为 playback 时可用。
边播边录
音频编码器（--audio-encoder） 音频编码器（--audio-encoder）指定 MediaCodec 音频编码器（可用的编码器名随 --audio-codec 的编码格式而定）。可用 scrcpy --list-encoders 列出设备上可用的编码器。
留空由 scrcpy 自动选择

码率与缓冲

音频码率（--audio-bit-rate） 音频码率（--audio-bit-rate）音频编码的比特率，scrcpy 默认 128 Kbps。只影响转发到电脑的音频，不影响设备自身的播放。
自动
采集缓冲（--audio-buffer） 采集缓冲（--audio-buffer）音频缓冲的时长，用来吸收网络抖动。调小会降低延迟，但更容易出现欠载、听感上是断音或爆音。
单位：毫秒
输出缓冲（--audio-output-buffer） 输出缓冲（--audio-output-buffer）电脑端音频输出缓冲的大小，scrcpy 默认 10 毫秒。除非确有需要不要改动：改小更容易出现播放断续。
单位：毫秒

控制

键鼠/手柄注入方式、快捷键、屏幕与剪贴板行为。默认参数。

输入注入

只读 / 仅查看（--no-control） 只读 / 仅查看（--no-control）只镜像、不注入：鼠标与键盘事件都不发给设备，等于只读查看。Flex Display 下该参数不参与拼装（scrcpy 判定不兼容）。
禁用设备控制
键盘（--keyboard） 键盘（--keyboard）选择键盘事件的注入方式。disabled 不向设备发送键盘事件；sdk 通过 Android 系统接口把事件投给应用；uhid 把电脑键盘模拟成设备上的物理键盘；aoa 用 AOAv2 协议模拟物理键盘，仅 USB 连接可用。uhid 与 aoa 需要先在设备的「设置 → 系统 → 语言和输入法 → 物理键盘」里配好键盘布局。
鼠标（--mouse） 鼠标（--mouse）选择鼠标事件的注入方式。disabled 不向设备发送鼠标事件；sdk 通过 Android 系统接口投递；uhid 模拟物理 HID 鼠标；aoa 用 AOAv2 协议模拟，仅 USB 连接可用。uhid 与 aoa 会捕获电脑鼠标（相对移动模式），按 LAlt、LSuper 或 RSuper 可把鼠标交还给电脑。
游戏手柄（--gamepad） 游戏手柄（--gamepad）选择手柄的注入方式。disabled 不向设备发送手柄事件；uhid 把电脑手柄模拟成设备上的物理手柄；aoa 用 AOAv2 协议模拟，仅 USB 连接可用。
快捷键修饰键（--shortcut-mod） 快捷键修饰键（--shortcut-mod）指定 scrcpy 快捷键的修饰键，默认是左 Alt 或左 Super。可同时选择多个，任一命中即触发；改动后所有快捷键的组合随之变化。
laltlsuperlctrlrctrlraltrsuper
不转发重复按键（--no-key-repeat） 不转发重复按键（--no-key-repeat）按住按键时不向设备转发重复事件。适合长按交给设备端自身连发的场景（如长按方向键连续翻页）。
按住按键时不转发重复事件

屏幕与剪贴板

显示触摸点（--show-touches） 显示触摸点（--show-touches）启动时打开设备的「显示点按操作反馈」，退出时恢复原值。只显示设备上的物理触摸，scrcpy 自己的鼠标点击不会显示。
演示可见点击
关闭屏幕（--turn-screen-off） 关闭屏幕（--turn-screen-off）启动后立即关闭设备屏幕，画面仍照常镜像，设备端的触控与按键照常可用。视频源为摄像头时不生效：此时画面不来自设备屏幕，熄屏无从谈起。
镜像时熄灭手机屏
保持唤醒（--stay-awake） 保持唤醒（--stay-awake）设备处于充电状态时保持屏幕常亮，退出镜像时恢复原值。不充电时不生效。
充电时保持亮屏
保持活跃（--keep-active） 保持活跃（--keep-active）通过模拟用户活动保持屏幕常亮，不依赖充电状态。与「充电时保持亮屏」的区别：这一项看的是有没有输入，而不是有没有插电。
模拟活动防息屏
关闭时锁屏（--power-off-on-close） 关闭时锁屏（--power-off-on-close）退出镜像时关闭设备屏幕，等价于按一次电源键。
退出即熄屏
剪贴板自动同步（--no-clipboard-autosync） 剪贴板自动同步（--no-clipboard-autosync）开启时剪贴板双向自动同步：向设备注入 Ctrl+V 之前先把电脑剪贴板推过去，设备剪贴板变化时同步回电脑。关闭后不再自动同步，两侧剪贴板互不影响。
双向同步（关闭时）
息屏超时（--screen-off-timeout） 息屏超时（--screen-off-timeout）scrcpy 运行期间把设备的息屏超时改为该秒数，退出时恢复原值。
单位：秒；0 / 留空 = 不修改设备设置

录制

录制镜像到文件，或仅录制不显示窗口。默认参数。

录制设置

启用录制（--record） 启用录制（--record）把镜像过程中的画面与声音录到文件，路径、格式与方向在下方设置。不勾选「后台录制」时窗口照常显示，录制与显示互不排斥。
保存到文件
文件路径 文件路径录制文件的保存路径，仅在启用录制时生效。扩展名决定容器格式（如 .mp4 / .mkv），与「格式」不一致时会得到名不副实的文件。
格式（--record-format） 格式（--record-format）强制录制文件的容器格式，仅在启用录制时生效。默认 mp4；与文件扩展名不一致时，文件内容与后缀会对不上。
录制方向（--record-orientation） 录制方向（--record-orientation）只影响录制文件的方向，不改变镜像画面。90 与 270 会交换输出文件的宽高。

无头与时限

无窗口仅录制（--no-window） 无窗口仅录制（--no-window）不打开 scrcpy 窗口，只在后台运行；控制仍可用，但看不到画面。没有同时开启录制时，这个会话将在完全看不到输出的情况下运行。
后台录制
时间限制（--time-limit） 时间限制（--time-limit）到时限后自动结束会话，常用在按固定时长录制时。
单位：秒；0 / 留空 = 不限时
退出时暂停（--pause-on-exit） 退出时暂停（--pause-on-exit）会话结束后暂停等待，而不是立即退出；选 if-error 时只在出错后暂停。它的原意是让命令行窗口停住，以便读报错；本应用会把 scrcpy 的输出收进会话日志，因此通常用不到。

窗口

scrcpy 窗口的标题、尺寸、位置与外观。默认参数。

外观

窗口标题（--window-title） 窗口标题（--window-title）自定义 scrcpy 窗口的标题，多设备同时投屏时可用来区分窗口。
留空 = 标题用设备名
无边框（--window-borderless） 无边框（--window-borderless）去掉窗口边框与标题栏，画面铺满整个窗口。没有标题栏后可拖动的区域消失，位置与大小需借助快捷键或启动参数调整。
隐藏装饰
全屏（--fullscreen） 全屏（--fullscreen）启动即进入全屏；退出全屏用 scrcpy 的全屏快捷键。
启动即全屏
置顶（--always-on-top） 置顶（--always-on-top）窗口始终压在其他窗口之上，适合边看手机边操作电脑。
最前显示
锁定宽高比（--no-window-aspect-ratio-lock） 锁定宽高比（--no-window-aspect-ratio-lock）scrcpy 默认锁定窗口宽高比；打开这个开关后可以自由拖动窗口大小，画面随之拉伸。只在使用 scrcpy 自带窗口时生效。
保持比例（关闭时）
背景色（--background-color） 背景色（--background-color）窗口留边区域（letterbox 黑边）的颜色，取值形如 #RGB 或 #RRGGBB。scrcpy 默认为 #222（深灰）。

尺寸与位置

宽度（--window-width） 宽度（--window-width）scrcpy 窗口的初始宽度（像素）。Flex Display 下窗口尺寸由 --new-display 决定，这一项不参与拼装。
0 / 留空 = 由 scrcpy 决定窗口大小
高度（--window-height） 高度（--window-height）scrcpy 窗口的初始高度（像素）。Flex Display 下窗口尺寸由 --new-display 决定，这一项不参与拼装。
0 / 留空 = 由 scrcpy 决定窗口大小
X（--window-x） X（--window-x）scrcpy 窗口初始位置的横坐标（屏幕像素）。填了它（或 Y）的设备不再参与窗口自动排列，窗口落在指定位置。
Y（--window-y） Y（--window-y）scrcpy 窗口初始位置的纵坐标（屏幕像素）。填了它（或 X）的设备不再参与窗口自动排列，窗口落在指定位置。
0 / 留空 = 由 scrcpy 自动决定

高级

连接后直接启动指定 App（虚拟显示场景尤其有用），用自定义参数兜底任何未覆盖的 flag，并可调整端口与隧道主机等网络参数。默认参数。

启动应用

包名（--start-app） 包名（--start-app）连接后直接在设备上打开指定应用；虚拟显示场景尤其有用，应用会开在新屏上。按名称匹配时 scrcpy 需要先读取设备上的应用列表，第一次可能稍慢。
支持 ? 模糊匹配 / + 强制停止；例如 --start-app=+?firefox：先强制停止再按名称模糊匹配启动。可配合虚拟显示器使用。

网络

客户端端口范围（--port） 客户端端口范围（--port）scrcpy 客户端监听并接收视频流的 TCP 端口，scrcpy 默认 27183:27199。同时连多台设备时会在范围内依次取用。
隧道主机（--tunnel-host） 隧道主机（--tunnel-host）指定 adb 隧道要连到的目标主机，默认 localhost。指定它之后 scrcpy 会自动改用 --force-adb-forward（不再尝试 adb reverse）。只有当设备端能访问另一台主机时才需要改。

自定义参数（直接透传给 scrcpy）

额外参数 额外参数把填写的内容原样追加到命令末尾，不做拆分与改写；界面没有提供的新 flag 也能这样用。它不属于设备覆盖：无论该设备是否启用覆盖，都会带上这段参数。引号必须成对，否则校验会拦下并给出提示。
对所有设备生效，直接追加到命令末尾

scrcpy 目录 scrcpy 目录未设置自定义目录时，约定目录为 ；设置了自定义目录时，scrcpy 与 adb 都从自定义目录读取，约定目录不再参与。首启若缺少二进制，可点「打开目录」手动放置，再点「重新检测」。
状态 状态未就绪时仍可查看路径与打开目录，或点「下载最佳适配版本」自动获取（下载通道 / 官方校验 / 原子替换）。
就绪 = 目录内 scrcpy 与 adb 齐备。
非最佳适配版本

当前版本非最佳适配版本，部分特性可能不受支持或存在未知问题。此提示不阻断任何操作，你仍可正常连接设备、发起会话与复制命令。

更新 更新两个入口都会删除并替换运行环境目录内的全部文件（scrcpy 与 adb 一起更新）；曾手动放入自定义版本请先备份。两者都从 GitHub Releases 获取：「下载最佳适配版本」取构建期锁定的受支持版本，不依赖官方最新发布查询；「下载最新版本」取官方最新发布，查询失败会回退到最佳适配版本并说明原因。直连失败会自动按序改用下面的代理地址，进度块会标明当前所用通道。直连虽可用但太慢时，可在进度块点「切换通道」立即换一条；下载完成后以官方 SHA256SUMS 校验，校验不通过不写入目录。

设置

管理本程序自身的外观、更新与日志：主题、字体、自动检查更新，以及会话输出与日志留存。改动即时生效并自动保存，不需要重启。

外观

界面语言 界面语言默认跟随系统语言；切换后立即生效，重启后保留。
主题模式 主题模式出厂默认跟随系统：取系统深浅色，运行期间随系统变化；选「深色」或「浅色」则固定，不再跟随系统。
主题色 主题色预设经过挑选，自定义主题色以可读性优先；点「自定义主题色」用系统或内核取色器取色。实底文字自动取白或黑，高亮与浅色文字按当前主题派生。

运行日志参数

日志级别（--verbosity） 日志级别（--verbosity）设置 scrcpy 的日志级别，决定会话日志里能看到多详细的过程信息。发布版 scrcpy 默认 info；调到 debug 或 verbose 会显著放大日志量。
显示 FPS 计数（--print-fps） 显示 FPS 计数（--print-fps）在日志里持续打印实际帧率，用来判断画面是否掉帧。
控制台打印帧率
关闭时清理（--no-cleanup） 关闭时清理（--no-cleanup）scrcpy 退出时会删除设备上的服务端程序，并还原它改动过的状态（显示触摸点、保持唤醒与电源模式）。打开这个开关即跳过清理：设备会保留这些改动，仅在排查问题时使用。
退出时还原设备状态（关闭时）
